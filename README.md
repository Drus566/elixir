# elixir
## Типы данных
```
Тип,    Пример,         Когда использовать?
Atom,   :active,        "Флаги, статусы, ключи."
String, "Elixir",       "Текст, сообщения."
List,   "[1, 2]",       "Коллекции данных, которые нужно перебирать."
Tuple,  "{:ok, val}",   Возврат результата из функции.
Map,    %{id: 1},       "Модели данных (пользователь, товар)."
```

## Пример записи &
```
[16, 21, 18, 12]
|> Enum.map(fn age -> %{age: age} end)          # Превращаем в список карт
|> Enum.map(fn user -> Validator.check(user) end) # Прогоняем через твой модуль
|> Enum.filter(fn {status, _msg} -> status == :ok end) # Оставляем только :ok

# Результат: [{:ok, "Welcome"}, {:ok, "Welcome"}]
Урок 1.8: Краткая запись функций (&)
В Elixir есть «синтаксический сахар» для анонимных функций, чтобы не писать каждый раз fn ... -> ... end.

Вместо: fn x -> x * 2 end Можно написать: &(&1 * 2)

& — начало функции.

&1 — первый аргумент, &2 — второй и так далее.

Твой пример выше стал бы еще короче: Enum.map(ages, &Validator.check(%{age: &1}))
```
